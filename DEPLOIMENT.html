🚀 Guide de Déploiement — Al Basîrah

Supabase (BDD + Auth) → GitHub (code) → Vercel (hébergement)

🟢 PARTIE 1 — Supabase (Base de données)

1 Exécuter le SQL principal

  1. Va sur supabase.com/dashboard
  2. Sélectionne ton projet
  3. Clique sur SQL Editor → + New query
  4. Colle le contenu de database.sql → clique Run ▶
  5. Attends le message Success

2 Exécuter les triggers

  1. Crée une nouvelle query dans SQL Editor
  2. Colle le contenu de triggers.sql → clique Run ▶
  3. Vérifie avec : SELECT * FROM public.global_stats;
Tu devrais voir : total_books = 14, total_audios = 10, total_videos = 8, total_scholars = 14

3 Récupérer tes clés API

Dans Supabase Dashboard :

  1. Clique sur Project Settings (icône engrenage)
  2. Clique sur API

4 Activer l'authentification email

  1. Supabase Dashboard → Authentication → Providers
  2. Active Email → coche "Confirm email"
  3. Configure l'URL de redirection : https://ton-site.vercel.app/connexion.html

5 Activer Realtime (pour les live viewers)

  1. Supabase Dashboard → Database → Replication
  2. Active Realtime sur les tables : live_sessions, scholars

🔵 PARTIE 2 — GitHub (code source)

1 Installer Git (si pas encore fait)

Télécharge Git sur git-scm.com et installe-le.

2 Créer un dépôt GitHub

  1. Va sur github.com → clique New repository
  2. Nom : al-basirah
  3. Visibilité : Private (recommandé)
  4. Clique Create repository

3 Préparer tes fichiers

Crée un dossier al-basirah/ sur ton ordinateur et mets-y :

al-basirah/
├── index.html
├── savants.html
├── savant.html
├── bibliotheque.html
├── live.html
├── categories.html
├── connexion.html
├── inscription.html
├── style.css
├── app.js
└── vercel.json
Ces fichiers sont tous dans le dossier téléchargé depuis Claude.

4 Pousser le code sur GitHub

Ouvre un terminal dans ton dossier al-basirah/ et exécute :

git init
git add .
git commit -m "Initial commit — Al Basirah"
git branch -M main
git remote add origin https://github.com/TON_USERNAME/al-basirah.git
git push -u origin main
Remplace TON_USERNAME par ton nom d'utilisateur GitHub.

⚫ PARTIE 3 — Vercel (hébergement)

1 Créer un compte Vercel

  1. Va sur vercel.com
  2. Clique Sign up → choisis Continue with GitHub
  3. Autorise Vercel à accéder à tes dépôts

2 Importer le projet

  1. Vercel Dashboard → clique Add New… → Project
  2. Cherche al-basirah dans la liste → clique Import
  3. Dans la configuration :
    • Framework Preset : Other
    • Root Directory : ./ (laisser par défaut)
    • Build Command : (vide — pas de build nécessaire)
    • Output Directory : ./

3 Ajouter les variables d'environnement

Dans la configuration Vercel, clique Environment Variables et ajoute :

NomValeur
VITE_SUPABASE_URLhttps://mutdtyifvcrkiouudwhr.supabase.co
VITE_SUPABASE_ANON_KEYeyJhbGciOiJIUzI1NiIs… (ta clé anon)
Comme ton site est en HTML/JS pur (pas Next.js), les variables d'env Vercel ne s'injectent pas automatiquement. Tes clés sont déjà dans app.js — c'est correct pour la clé anon publique.

4 Déployer

  1. Clique Deploy
  2. Vercel déploie en ~30 secondes
  3. Tu obtiens une URL : https://al-basirah.vercel.app

5 Configurer l'URL Supabase Auth

Maintenant que tu as l'URL Vercel, retourne dans Supabase :

  1. Authentication → URL Configuration
  2. Site URL : https://al-basirah.vercel.app
  3. Redirect URLs : ajoute https://al-basirah.vercel.app/connexion.html

6 Déploiements automatiques (bonus)

Désormais, chaque git push redéploie automatiquement ton site sur Vercel !

# Modifier un fichier, puis :

🌐 PARTIE 4 — Domaine personnalisé (optionnel)

1 Acheter un domaine

Exemples de registrars : Namecheap, GoDaddy, OVH

Domaines suggérés : albasirah.com / al-basirah.net / albasirah.fr

2 Connecter à Vercel

  1. Vercel Dashboard → ton projet → Settings → Domains
  2. Clique Add → entre ton domaine
  3. Vercel te donne deux enregistrements DNS à configurer chez ton registrar :
    • Type A : 76.76.21.21
    • Type CNAME : cname.vercel-dns.com
  4. Attends 5–30 min → SSL activé automatiquement ✅
